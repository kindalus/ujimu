# Ujimu Prototype

Protótipo estático em React carregado via CDN/Babel no browser.

## Requisitos

- Node.js 20+

## Setup

```bash
npm install
```

## Correr em desenvolvimento

```bash
npm run dev
```

Depois abrir o endereço indicado pelo Vite, normalmente:

```text
http://localhost:5173/
```

> Nota: `offline.html` é um ficheiro exportado/pesado e está ignorado no `.gitignore`.
