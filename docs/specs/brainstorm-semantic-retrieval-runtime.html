Brainstorm aprovado

Paráfrases encontram o hint certo

Adicionar embeddings E5 como fallback ao retrieval actual, com threshold 0.92 e sem substituir correspondências exactas.

Objectivo

Recuperar formulações semanticamente equivalentes

  • Manter exact match como primeira escolha.
  • Manter o trigram Dice forte antes do fallback semântico.
  • Usar E5 apenas quando os métodos existentes não encontram hint.
  • Não guardar respostas nem embeddings de texto de clientes.
Contexto aplicável

Decisões já tomadas

Modelo

Xenova/multilingual-e5-small, INT8, 384 dimensões.

Runtime

@huggingface/transformers@4.2.0, API validada com 200 casos.

Threshold

0.92, escolhido como política mais conservadora.

Dados

Cache futura em <UJIMU_DATA_DIR>/models/transformers.

Risco aceite

Advisories não bloqueiam esta integração

  • sharp@0.34.5 e adm-zip@0.5.x permanecem sinalizados como high.
  • O utilizador mandou ignorar esses advisories em 2026-09-08.
  • A excepção deve ficar explícita; não será apresentada como audit limpo.
  • O pacote continua sujeito a assinaturas, isolamento de dados e testes.
Fluxo proposto

Híbrido e degradável

1 · Exacto

Fingerprint igual devolve os paths existentes.

2 · Lexical

Trigramas com o limiar actual continuam sem alteração.

3 · Semântico

E5 compara a pergunta com candidatos ainda válidos.

4 · Falha

Se o modelo não carregar, a conversa continua com retrieval lexical.

Limites

Não transformar isto num vector DB

  • Sem serviço externo de embeddings.
  • Sem resposta em cache.
  • Sem pesquisa entre especialistas.
  • Sem download do modelo no caminho crítico de uma pergunta.
  • Sem alteração de raw/ ou das páginas wiki.
Decisões tomadas

Operação e margem fechadas

Flag de activação

Produção activa a funcionalidade por variável de ambiente e conserva rollback imediato.

Pré-carregamento

A cache persistente é preparada antes do deploy e o processo aquece o modelo no arranque.

Margem 0.003

O fallback exige score mínimo 0.92 e diferença top-2 mínima 0.003.

Excepção temporária

Os advisories são aceites até existir uma versão compatível sem os problemas conhecidos.
