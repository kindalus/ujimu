Arquitectura

Auto-expansão no composer existente

Decisão de arquitectura para a melhoria pequena do input de chat.

Base aceite

Não vamos redesenhar o chat

  • O formulário actual em pages/index.vue continua a ser a superfície de interacção.
  • O textarea.prompt-ta mantém o envio por Enter e nova linha por Shift+Enter.
  • O CSS actual em assets/css/main.css continua a controlar a aparência do composer.
Decisão técnica

Altura calculada no cliente

  • Usar uma referência ao textarea e recalcular após alterações de question.
  • Medir line-height e padding computados para obter exactamente cinco linhas visíveis.
  • Aplicar height inline até ao limite; depois activar overflow-y: auto.
Exclusões

Sem abstracção nova

  • Não extrair um novo componente de composer.
  • Não migrar para outro componente Nuxt UI neste slice.
  • Não alterar quota, fila, histórico, selecção de especialidade ou streaming.
Verificação

Critérios

  • Teste de aceitação confirma constantes, referência do textarea, watcher e limite de cinco linhas.
  • Typecheck deve passar.
  • O composer mantém a semântica de teclado existente.
