Arquitectura

Copiar resposta com fontes

Desenho mínimo para acrescentar uma acção local no chat sem alterar APIs, quotas, histórico ou ingestão.

Origem

Deck aprovado

  • Origem: docs/specs/brainstorm-chat-message-actions.html.
  • Escopo aprovado: apenas copiar resposta para a área de transferência.
  • Arquitectura aprovada explicitamente pelo utilizador.
  • Sem docs/wiki/; contexto governante vem de AGENTS.md, specs e código actual.
  • UI visível em português europeu pré-Acordo.
Princípio técnico

Cliente apenas

Sem API

Não há alteração de servidor, base de dados, quotas, histórico ou contratos de chat.

Página actual

A implementação vive em pages/index.vue, junto da renderização das mensagens.

Modelo de interacção

Acção por resposta

  • Mostrar botão Copiar resposta apenas em mensagens do assistente.
  • Desactivar/ocultar enquanto a mensagem ainda está em streaming.
  • Ao clicar, montar texto com resposta e secção Fontes.
  • Usar navigator.clipboard.writeText quando disponível.
Formato copiado

Texto simples estruturado

  • Primeira parte: texto integral da resposta.
  • Se existirem citações: adicionar linha vazia e cabeçalho Fontes:.
  • Cada fonte inclui título, artigos/referências e ficheiro quando existir.
  • Sem HTML, sem metadados sensíveis, sem identificadores internos de mensagem.
Estados e acessibilidade

Feedback simples

  • Guardar estado local copiedMessageId e copyErrorMessage.
  • Mostrar Resposta copiada. junto da mensagem copiada.
  • Mostrar erro curto se o browser bloquear a área de transferência.
  • Botão normal, focável por teclado, com texto visível.
Exclusões

Não fazer agora

  • Não copiar perguntas.
  • Não regenerar respostas.
  • Não apagar mensagens individuais.
  • Não partilhar conversas ou criar URLs públicos.
  • Não alterar histórico, analytics, quotas ou API de chat.
Verificação

Critérios de sucesso

  • Teste UI confirma botão em respostas e ausência em perguntas.
  • Teste confirma inclusão de resposta, fontes, artigos e ficheiro.
  • Teste confirma uso de navigator.clipboard.writeText e feedback.
  • typecheck, testes, build e audit continuam verdes.
Decisão

Arquitectura proposta

Aprovado: usar a arquitectura existente do chat, acrescentando apenas uma acção client-side de cópia por mensagem de assistente concluída.
