Slice 25

Upload, substituição e refresh de fontes

Trocar o modelo de “recarregar fontes” global por gestão explícita de fonte oficial: upload local, substituição controlada e actualização de estado.

Escopo

Fonte como unidade operacional

  • Upload continua a receber ficheiro escolhido no computador do utilizador.
  • Upload com o mesmo nome lógico substitui a fonte actual de forma segura.
  • A fonte anterior fica marcada internamente como substituída, sem aparecer como histórico na UI.
  • A UI usa “Actualizar estado” para ler estado actual das fontes oficiais.
  • Remover da UI os botões “Recarregar fontes” e “Executar conversão”.
Refinamento

Substituir pelo mesmo nome lógico

  • O mesmo nome de upload normalizado aponta para a mesma fonte oficial.
  • Se o ficheiro ainda não existe, é um upload inicial.
  • Se já existe, o conteúdo é sobrescrito e a fonte fica pendente de nova ingestão.
  • A marca interna usa checksum anterior e data de substituição; a UI não lista versões antigas.
Grill

Decisões bloqueadas

  • Manter auditoria administrativa separada para raw_source_uploaded e raw_source_replaced.
  • Preservar validação de extensão, content-type e caminho seguro dentro de raw/.
  • Após upload ou substituição, o endpoint actualiza o estado da fonte imediatamente para que o admin não precise de “redetectar”.
  • O botão visual chama-se “Actualizar estado” e apenas lê/actualiza a zona de fontes oficiais.
  • A UI deixa de oferecer “Executar conversão”; a rota antiga fica fora da UI neste slice.
Testes

Aceitação planeada

  • Segundo upload com o mesmo nome substitui a fonte em vez de devolver conflito.
  • Estado da fonte substituída contém checksum anterior e fica pendente/bloqueado conforme o tipo.
  • Auditoria distingue upload inicial de substituição sem guardar conteúdo da fonte.
  • A página de detalhe mostra “Actualizar estado” e não mostra “Recarregar fontes” nem “Executar conversão”.
Exclusões

Não entra

  • Não executar Pi neste slice.
  • Não implementar fila recuperável neste slice.
  • Não remover rotas antigas ainda; só deixar a UI de as usar quando seguro.
