Slice 34

API corporativa de especialistas

Criar a superfície server-side para admins de empresa listarem especialistas privados, editarem o prompt e carregarem fontes sem ingestão.

Origem

Contexto governante

  • Brainstorm aprovado: ../brainstorm-corporate-specialist-source-management.html.
  • Arquitectura aprovada: ../corporate-specialist-source-management-architecture.html.
  • Admin corporativo só gere especialistas com company_id da sua empresa.
  • Ingestão permanece tarefa do admin Ujimu.
Âmbito

Contratos API

  • GET /api/companies/:id/specialists
  • GET /api/companies/:id/specialists/:specialistId
  • PATCH /api/companies/:id/specialists/:specialistId só para system_prompt.
  • POST /api/companies/:id/specialists/:specialistId/raw para upload/substituição.
  • Auditoria corporativa para prompt e upload.
Decisões refinadas

Segurança e simplicidade

  • Reutilizar requireCompanyAdmin().
  • Especialista errado ou de outra empresa devolve 404.
  • Não criar jobs nem chamar conversão/ingestão.
  • Upload substitui fonte com o mesmo nome lógico.
  • Audit metadata nunca guarda conteúdo nem prompt.
Zonas prováveis

Ficheiros

  • server/api/companies/[id]/specialists/**
  • server/utils/companies/specialists.ts
  • server/utils/db.ts
  • tests/company-specialists.acceptance.test.ts
  • tests/db.test.ts
Sucesso

Critérios de aceitação

  • Admin de empresa lista apenas especialistas da sua empresa.
  • Membro não-admin, anónimo e empresa errada são bloqueados.
  • PATCH rejeita campos fora de system_prompt.
  • Upload cria/substitui fonte, actualiza estado e não agenda ingestão.
  • Eventos auditáveis ficam sanitizados.
Exclusões

Não entra

  • Sem UI corporativa; isso é Slice 35.
  • Sem criação/eliminação/associação de especialistas.
  • Sem alteração de chat, quotas, billing ou ingestão.
  • Sem prompt por empresa.
