Slice 17

Chat com Nuxt UI

Substituir o ecrã principal por uma experiência de chat directa, com prompt, mensagens e selector de especialista na zona correcta.

Referências

Origem e dependência

  • Depende do slice 16 para shell e drawer.
  • Brainstorming: ../brainstorm-ui-redesign.html.
  • Arquitectura: ../ui-redesign-architecture.html.
  • Antes de implementar, consultar documentação oficial do Nuxt UI para componentes UChat*.
Escopo

Chat primeiro, sem hero

  • Remover o bloco de boas-vindas em estilo hero.
  • Usar componentes UChatMessages, UChatMessage, UChatPrompt e UChatPromptSubmit quando encaixarem.
  • Criar adaptador visual de mensagens Ujimu para formato UIMessage/parts, sem mudar o backend.
  • Colocar dropdown de especialista no prompt.
  • Mostrar informação do especialista dentro do painel de mensagens quando a conversa está vazia.
Citações

Grounding continua intacto

  • Citações aparecem no fim das respostas do assistente.
  • Mensagens sem evidência válida continuam a usar fallback de contexto insuficiente.
  • O selector de especialista não permite misturar conversas sem iniciar nova consulta.
  • A fila de perguntas continua visível e scoped ao especialista activo.

Condições de sucesso

Verificação do slice

  • O ecrã inicial começa no chat e mostra informação do especialista na área de mensagens.
  • O especialista é escolhido no prompt.
  • Respostas e citações continuam a renderizar correctamente.
  • Streaming, fila, edição de pergunta e fallback de grounding continuam cobertos por testes.
Exclusões

O que não entra

  • Não mover subscrições nem login neste slice.
  • Não inserir publicidade em linha ainda.
  • Não redesenhar admin.
  • Não alterar o endpoint /api/chat.
