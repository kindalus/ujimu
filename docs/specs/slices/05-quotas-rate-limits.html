Slice 5

Quotas & request limits

Enforce anonymous, registered, and subscribed request limits before invoking the AI engine.

server-side user timezone request = question
Idea

Every question has a cost.

A request is each question sent by the user, including a question sent after editing an earlier point in a conversation.

Refined direction

Protect anonymous chat first.

  • Integrate quota enforcement into chat for anonymous first-time visitors in this slice.
  • Keep policy support for anonymous, registered free, and subscribed subjects testable in server code.
  • Do not build authentication, subscription activation, or account UI here.
  • Use an httpOnly server-issued anonymous identifier cookie; SQLite remains the authority for quota state.
Minimum success

Block before the stream starts.

  • Anonymous users are limited to 5 requests per day or 20 requests per week.
  • Quota checks happen before chat creates an AI stream or calls the engine.
  • Quota denials return HTTP 429 JSON and do not create assistant turns.
  • Registered and subscribed policy logic is covered by tests, but not connected to real auth yet.
Locked decisions

Windows and consumption.

  • Daily windows use the user's validated timezone.
  • Weekly windows are local ISO weeks: Monday 00:00 to the following Monday 00:00.
  • Quota is consumed after request validation and specialist lookup, immediately before stream creation.
  • Invalid requests and missing specialists do not consume quota.
  • If chat fails after quota is allowed, the request still counts in this slice.
Locked decisions

Anonymous identity and limits.

  • Create the anonymous cookie only on the first valid chat request.
  • Cookie name: ujimu_anon_id; value: server-generated UUID.
  • Cookie options: httpOnly, sameSite=lax, secure in production, maxAge 180 days.
  • Invalid or missing timezone falls back to Africa/Luanda.
  • Subscribed weekly limit comes from UJIMU_SUBSCRIBED_WEEKLY_LIMIT, default 5000.
Locked decisions

Denials and queue behaviour.

  • Quota denials return HTTP 429 JSON before streaming.
  • The 429 body includes only exceeded limits with limit, used, and resetAt.
  • If daily and weekly are both exceeded, include both limit objects.
  • The frontend shows quota errors above the composer, not as assistant messages.
  • If a queued question hits 429, stop processing the queue and keep pending questions visible.
Policy table

Initial quota policy.

Anonymous5 requests per day or 20 requests per week, associated with a browser cookie.
Registered free20 requests per day and 100 requests per week.
SubscribedNo daily limit; configurable weekly limit, initially 5000.
Authority

Cookies identify; the server decides.

  • Client cookies are identifiers, not quota state.
  • Anonymous cookies are server-issued, httpOnly, and contain only an opaque identifier.
  • All counters and decisions live server-side in SQLite.
  • Quota denial happens before Pi is invoked and before streaming starts.
  • A failed or denied request should not consume AI resources.
Timezone

Daily and weekly windows use the user timezone.

  • Registered users store a preferred or last-seen valid IANA timezone.
  • Anonymous users provide browser timezone and receive a cookie-bound identity.
  • Invalid or missing timezone falls back to a safe default.
  • Weekly windows must be consistently defined and documented in code.
Data model

Prefer event records over fragile counters.

request_events
  id
  subject_type: anonymous | user
  subject_id
  specialist_id
  conversation_id
  occurred_at_utc
  user_timezone
  counted: boolean
  decision: allowed | denied
  denial_reason
The table is append-only for this slice. Allowed and denied attempts are recorded; denied events are not counted against quota.
User feedback

Quota messages should guide the next action.

  • Anonymous users should be invited to register when they hit the limit.
  • Registered free users should be invited to subscribe.
  • Subscribed users should see weekly reset information when the weekly cap is reached.
  • All user-facing copy follows pt-PT pre-1990 orthography.

Success conditions

What must be true when the slice is done.

  • Anonymous chat requests are blocked after 5 per day or 20 per week.
  • Anonymous, registered free, and subscribed subjects receive the correct effective quota in policy tests.
  • Daily and weekly limits reset according to the user timezone.
  • Quota checks run before the AI stream begins.
  • Denied requests return HTTP 429 JSON and do not call the chat engine.
  • Editing an earlier question and sending the replacement counts as a new request once history editing exists.
  • Changing configured subscribed weekly limits takes effect without code changes.
