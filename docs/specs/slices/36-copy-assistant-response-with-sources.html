Slice 36

Copiar resposta com fontes

Acrescentar uma acção in-chat simples para copiar a resposta do assistente com as citações de suporte.

Origem

Decks aprovados

  • Brainstorm: ../brainstorm-chat-message-actions.html.
  • Arquitectura: ../chat-message-actions-architecture.html.
  • Sem docs/wiki/; aplicam-se AGENTS.md, specs existentes e código actual.
  • Escopo reduzido: apenas copiar resposta com fontes.
Ideia

Uma acção por resposta

  • Mostrar Copiar resposta em mensagens do assistente concluídas.
  • Não mostrar a acção em perguntas do utilizador.
  • Não mostrar/activar durante streaming.
  • Manter a experiência actual de edição, histórico, fila e citações.
Implementação provável

Zona única

UI

pages/index.vue: estado local, função de formatação, função de cópia e botão junto das respostas.

Testes

tests/chat-ui.acceptance.test.ts ou novo teste UI focado no conteúdo da página.

Formato

Texto simples

  • Copiar primeiro o texto exacto da resposta.
  • Quando houver citações, acrescentar Fontes:.
  • Cada fonte inclui título, referências/artigos e ficheiro quando existir.
  • Não copiar identificadores internos, estado da mensagem ou dados de quota.
Feedback

Visível e acessível

  • Depois de copiar: mostrar Resposta copiada..
  • Se a área de transferência falhar: mostrar erro curto.
  • Usar botão normal e texto visível, sem depender apenas de ícones.
  • Sem modais ou notificações globais para esta acção pequena.
Exclusões

Fora do slice

  • Copiar perguntas.
  • Regenerar respostas.
  • Apagar mensagens individuais.
  • Partilhar conversas.
  • Alterar API, histórico, analytics, quotas ou base de dados.
Sucesso

Condições verificáveis

  • Teste RED confirma que a UI ainda não tem cópia de resposta.
  • Teste GREEN confirma botão, chamada ao clipboard e texto formatado com fontes.
  • npm run typecheck, npm test, npm run build e audit passam.
  • Sem alterações fora do escopo da página de chat e documentação Zafir.
Refinação

Direcção escolhida

  • Problema: como permitir que o utilizador reutilize uma resposta sem perder as fontes?
  • Direcção: botão pequeno por resposta concluída, com texto claro.
  • Hipótese: texto simples estruturado é suficiente para colar em e-mail, documento ou chat.
  • Não criar componente novo; manter a alteração junto do fluxo actual de mensagens.
Estado

Refinado

O slice está pronto para grill, teste de aceitação e implementação TDD.
