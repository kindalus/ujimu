Slice 52 · planeado

Desempenho de carregamento medido

Origem: ../brainstorm-seo-performance-launch.html e ../seo-performance-launch-architecture.html.

Âmbito

Base repetível de Lighthouse/Core Web Vitals, pedidos, bytes e TTFB em produção.

Hipóteses

SSR da lista pública, estado partilhado de features e carregamento tardio de UI secundária.

Regra

Manter apenas alterações cujo ganho supere a variação entre medições.

Metas

Performance ≥90, LCP ≤2,5 s, CLS ≤0,1 e INP ≤200 ms no perfil aprovado.

Zonas prováveis

Página inicial, estado de aplicação, componentes tardios, Nginx e CI.

Exclusões

Sem micro-optimizações sem prova, cache público de dados privados ou perda funcional.
