Slice 35

UI corporativa de especialistas

Adicionar a página Nuxt onde admins de empresa gerem prompt, upload de fontes e estados dos especialistas privados da empresa.

Origem

Contexto governante

  • Brainstorm aprovado: ../brainstorm-corporate-specialist-source-management.html.
  • Arquitectura aprovada: ../corporate-specialist-source-management-architecture.html.
  • API do Slice 34 deve estar verde antes deste slice.
  • UI copy em português europeu pré-AO90.
Âmbito

Experiência de empresa

  • Adicionar rota /companies/:id/specialists.
  • Adicionar link em /companies/:id para admins da empresa.
  • Listar especialistas privados da empresa.
  • Permitir editar system_prompt, carregar fontes e ver estados.
  • Mostrar aviso de que ingestão é feita pelo admin Ujimu.
Decisões refinadas

Sem operações Ujimu

  • Não mostrar criar/apagar especialistas.
  • Não mostrar estado/empresa/citações como campos editáveis.
  • Não mostrar botões de conversão, ingestão ou fila.
  • Erros 401/403/404 têm mensagens simples.
  • Usar componentes Nuxt UI já adoptados no produto.
Zonas prováveis

Ficheiros

  • pages/companies/[id]/specialists.vue
  • pages/companies/[id].vue
  • utils/admin-ui.ts ou novo util partilhado se necessário.
  • tests/company-specialists-ui.acceptance.test.ts
Sucesso

Critérios de aceitação

  • Página e link existem.
  • UI chama endpoints corporativos, não /api/admin.
  • Contém editor de prompt e upload.
  • Contém lista de fontes e estados.
  • Não contém acções de ingestão/conversão/criação/eliminação.
Exclusões

Não entra

  • Sem novo backend; isso é Slice 34.
  • Sem redesign da página de empresas.
  • Sem browser E2E obrigatório neste slice.
  • Sem alteração ao chat.
Fim

Funcionalidade completa

Depois deste slice, admins corporativos conseguem contribuir fontes, acompanhar estados e ajustar o prompt dos seus especialistas privados.
