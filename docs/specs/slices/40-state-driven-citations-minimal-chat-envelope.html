Slice 40

Citações por estado e envelope mínimo

Gerar a allowlist a partir do estado enriquecido e reduzir o prompt de chat ao protocolo técnico indispensável.

Origem

Decks aprovados

  • ../brainstorm-agent-managed-specialist-wiki.html.
  • ../agent-managed-specialist-wiki-architecture.html.
  • Depende do estado enriquecido do Slice 39.
Ideia

Comportamento no AGENTS.md

  • system_prompt do especialista é opcional.
  • Instruções substantivas de resposta vivem no AGENTS.md.
  • Backend não injecta estilo, tom ou regras editoriais amplas.
  • Backend mantém validação de segurança e citação.
Envelope

O mínimo que o agente precisa

  • Pergunta do utilizador.
  • Identidade do especialista.
  • Allowlist de citações gerada por ingest/state.json.
  • Formato técnico de eventos de streaming.
  • Sem instruções substantivas duplicadas do AGENTS.md.
Allowlist

Estado backend-owned

  • Ler citações validadas do estado enriquecido.
  • Continuar a aceitar apenas fontes ingeridas.
  • Rejeitar citações fora da allowlist.
  • Se grounded=true sem citação válida, tratar como falha de fundamentação.
Zonas prováveis

Implementação esperada

  • server/utils/chat/context.ts — evidência de citação a partir de estado enriquecido.
  • server/utils/chat/pi-runner.ts — prompt/envelope mínimo.
  • server/utils/specialists/schema.ts — prompt opcional alinhado.
  • Testes de chat para citação obrigatória, prompt limpo e estado insuficiente.
Exclusões

Fora deste slice

  • Não implementar UI admin de logs.
  • Não alterar a taxonomia wiki.
  • Não criar novas regras de conteúdo fora do AGENTS.md.
  • Não aceitar citações geradas só por texto livre do agente.
Sucesso

Condições verificáveis

  • Chat usa allowlist do estado enriquecido.
  • Prompt técnico não contém instruções editoriais amplas removidas para o AGENTS.md.
  • Citação inválida é filtrada/rejeitada.
  • Resposta fundamentada sem citação válida não é emitida como fundamentada.
Refinação

Direcção escolhida

  • Usar apenas ingestion.citations validadas pelo manifesto.
  • Não promover metadados legados de fonte para allowlist.
  • Remover system_prompt do prompt de chat; a inicialização deve incorporá-lo no AGENTS.md quando existir.
  • Manter no prompt só o envelope técnico: pergunta, especialista, contexto, allowlist e NDJSON.
Grill

Decisões fechadas

  • Fonte ingerida sem ingestion.citations não é evidência utilizável.
  • O fallback seguro continua activo quando a allowlist fica vazia.
  • O backend ainda filtra citações emitidas pelo agente contra a allowlist exacta.
  • O system prompt administrativo não é injectado em primeira pergunta nem em continuação.
Implementação

Concluída

  • server/utils/chat/context.ts agora faz flatMap das citações validadas no estado.
  • server/utils/chat/citations.ts exige citações validadas.
  • server/utils/chat/pi-runner.ts usa envelope técnico mínimo.
  • Testes de chat/histórico/analytics foram actualizados para semear citações validadas.
