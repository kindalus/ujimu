Convergência do wiki após ingestão

Não terminar a ingestão enquanto uma nova verificação ainda encontrar problemas corrigíveis no wiki.

Problema

Ingerir não prova coerência global

  • O prompt actual exige conversão, ingestão, índice, log e manifesto.
  • A skill llm-wiki já define lint de conformidade, linhagem, ligações, contradições e conteúdo obsoleto.
  • O prompt não obriga a executar esse lint no fim.
  • Uma fonte nova pode deixar páginas individualmente válidas, mas mutuamente incoerentes.
Contexto governante

Corrigir sem inventar

  • raw/ continua imutável e converted/ continua não curado.
  • As correcções incidem em wiki/, índice, log e ligações.
  • Contradições factuais não podem ser apagadas só para produzir uma aparência de consistência.
  • Problemas que exigem confirmação humana devem permanecer explícitos no manifesto, nunca resolvidos por adivinhação.
  • Não existe docs/wiki/; governam AGENTS.md, a skill llm-wiki, specs e código.
Direcções avaliadas

“Até convergência” precisa de um critério

Uma verificação

É barata, mas não detecta problemas introduzidos pelas próprias correcções.

Número fixo de passagens

Evita ciclos longos, mas pode parar ainda com problemas ou gastar passagens inúteis.

Uma passagem limpa

Repetir lint e correcção até uma passagem completa não encontrar novo problema corrigível.

“Corrigir tudo” sem fronteira

Arrisca inventar factos ou entrar num ciclo sem condição verificável de saída.

Direcção proposta

Convergência significa uma passagem limpa

  • No fim da ingestão, verificar conformidade, linhagem, links, páginas órfãs, duplicações, conteúdo obsoleto, contradições e coerência transversal.
  • Corrigir automaticamente o que as fontes actuais permitem resolver sem ambiguidade.
  • Repetir verificação e correcção até uma passagem completa não produzir novo problema corrigível.
  • Não encobrir conflitos legítimos entre fontes; representá-los segundo o schema.
  • Registar problemas que exigem confirmação em failed[] ou warnings.
Fora do âmbito

Só o contrato do prompt

  • Não alterar modelo, nível de raciocínio ou ferramentas.
  • Não criar um segundo serviço de lint no backend.
  • Não modificar o formato do manifesto.
  • Não fazer uma limpeza autónoma de fontes brutas ou conversões.
  • Não transformar desacordo entre fontes em falsa concordância.
Decisão aprovada

Convergência por passagem limpa

A alteração exacta será aplicada ao prompt batch e ao prompt antigo de fonte única, para que ambos terminem apenas depois de uma passagem limpa ou registem o bloqueio.

  • Iteração 1: o utilizador pediu verificação, correcção e continuação até convergência.
  • Recomendação: definir convergência como uma passagem sem novos problemas corrigíveis.
  • Iteração 2, 2026-08-23: o utilizador aprovou toda a direcção e autorizou a implementação.
