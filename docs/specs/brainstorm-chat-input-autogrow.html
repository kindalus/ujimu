Input de chat auto-expansível

Refinar uma melhoria pequena de experiência: o campo de pergunta deve crescer para cima até cinco linhas e, depois disso, usar scroll interno.

Objectivo e valor

Como poderemos tornar perguntas longas mais confortáveis sem roubar o ecrã ao chat?

  • O utilizador escreve consultas mais longas com contexto legal, fiscal, laboral ou aduaneiro.
  • O composer deve mostrar várias linhas antes do envio, evitando cortes prematuros.
  • A área de mensagens deve continuar dominante; o input não deve crescer indefinidamente.
Contexto do repositório

Base actual observada

  • pages/index.vue usa um textarea.prompt-ta dentro do composer inferior.
  • assets/css/main.css já impede resize manual e define max-height: 160px.
  • O envio por Enter simples já é tratado em @keydown.enter.exact.prevent.
  • Os testes de UI inspeccionam strings do ficheiro, pelo que a alteração deve ter aceitação explícita.
Direcções possíveis

Variações a considerar

CSS apenas

Limitar altura e activar scroll, mas sem ajuste real ao conteúdo.

Textarea auto-ajustado

Recalcular altura pelo scrollHeight até cinco linhas.

Componente dedicado

Extrair um composer reutilizável. Mais limpo, mas maior superfície.

Nuxt UI prompt

Migrar para o componente real. Fora de escopo para esta melhoria pequena.

Direcção recomendada provisória

Alteração cirúrgica no textarea existente

  • Manter o composer actual e ajustar só o comportamento do textarea.
  • Usar uma referência ao elemento para calcular altura após alteração do texto.
  • Definir altura máxima equivalente a cinco linhas e activar scroll só depois desse limite.
  • Preservar o crescimento para cima naturalmente, porque o composer está fixo no fim do fluxo.
Decisões aprovadas

Âmbito confirmado

  • O comportamento aplica-se a todos os utilizadores do chat: anónimos, registados, subscritores e administradores.
  • Shift+Enter continua a inserir nova linha; Enter simples continua a enviar a pergunta.
  • Ao limpar, enviar, cancelar edição, escolher especialidade ou iniciar nova consulta, o campo deve voltar a uma linha.
  • O limite é exactamente cinco linhas visíveis; a partir daí há scroll interno no campo.
Registo de iteração
