Slice 3

Legislation wiki & raw ingestion

Accept official source files, detect pending ingestion, and maintain ingestion state for public legislation/regulatory wikis.

raw/ PDF/TXT/MD legislation-regulatory no OCR
Idea

Official files enter raw/ before becoming knowledge.

The app should never treat uploads as answered knowledge until they are ingested into the specialist wiki with traceable metadata.

Source rules

The MVP keeps source handling simple.

  • Accepted sources are files such as PDF, TXT, Markdown, and similar text-bearing formats.
  • Files are stored under the specialist raw/ directory.
  • There is no raw file size restriction in the MVP.
  • In this slice, textual sources are ingested; PDFs are accepted and detected but marked unsupported when ingestion runs.
  • OCR is out of scope; scanned PDFs that cannot be read are reported as unsupported for now.

Citation metadata

Prepare citations before chat needs them.

  • Store the original file title or inferred legal instrument title.
  • For legislation, record titles, chapters, articles, and effective dates when available.
  • Do not expose internal wiki page names as user-facing citations.
  • Keep traceability from citation to raw file and wiki synthesis.
Pi role

Pi maintains the wiki; the app orchestrates.

  • The app detects source files and starts ingestion work.
  • Pi SDK runs in-process, scoped to the specialist directory.
  • Pi uses file tools only: read, write, edit, grep, find, and ls; no bash by default.
  • Real Pi ingestion requires UJIMU_PI_INGESTION_ENABLED=true.
  • The app records status and makes ingested knowledge available to chat.
  • Failures remain visible for admin review.

Success conditions

What must be true when the slice is done.

  • Server-side source storage places a source in the correct specialist raw/ directory.
  • Startup and manual reload identify raw files that have not been ingested.
  • Already-ingested files are not duplicated when unchanged.
  • Pi ingestion runs one textual source at a time when explicitly enabled.
  • When Pi ingestion is disabled, pending files remain pending.
  • Unreadable or unsupported PDFs are reported without corrupting ingestion state.
  • Ingested legislation sources produce citation metadata based on original file titles and legal article references.
